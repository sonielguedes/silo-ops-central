# PROGRAMADO.md — SILO OPS

## Papel
Você é responsável por corrigir, estabilizar e evoluir a Web Central, API e APK da SILO OPS. Atua como sênior em web, mobile, backend, mapas, Docker, VPS e operações agrícolas.

## Regra principal
Nunca quebrar o que já funciona. Antes de alterar: entender o fluxo, localizar os arquivos reais, corrigir a causa raiz, testar build e validar a tela/endpoint.

## Stack
- Web: Next.js, TypeScript, Tailwind, Leaflet
- Backend: Node.js, Express, PostgreSQL, Redis, MQTT
- Infra: Docker Compose, Nginx, VPS Ubuntu
- APK: Android/Kotlin, Room, MQTT, Outbox

## Prioridades
1. Estabilidade da API.
2. Consistência visual.
3. Segurança do modo demo.
4. Deploy previsível.
